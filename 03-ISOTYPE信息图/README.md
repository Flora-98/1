# 03｜ISOTYPE信息图：独立设计方法专项

ISOTYPE（International System of Typographic Picture Education）作为独立的视觉表达方法与社会信息传播系统管理，不作为五种基础信息图形类型之一，也不作为02目录的市场表现标签。

## 研究内容
- 历史背景、理论来源与关键实践者
- 图像符号词汇的标准化与语义一致性
- 重复单位、数量映射、比例表达和图例规则
- 文字、图表、地图与叙事的协同
- 历史案例档案、来源与版权记录
- 当代信息设计中的方法转译及边界

## 案例录入
每件历史作品独立建立CASE档案，记录题名、设计者/机构、年份、出版物/馆藏编号、原始来源、图片权利、符号系统、数量规则、数据结构、叙事结构和证据等级。原图不可公开再发布时只保留馆藏/出版方链接。

## 真实性判定
仅使用图标不等于ISOTYPE。至少应核查图像符号是否构成系统化词汇、是否标准化重复、是否承担数量或社会事实表达、是否有可靠历史来源。现代作品可标记为“受ISOTYPE启发”，不可直接冒充历史ISOTYPE作品。
