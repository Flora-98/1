# 04-XXX主题信息图形设计

复制本目录作为新主题项目，将 XXX 替换为实际主题。

## 项目阶段
1. `01-前期调研`：目标、受众、传播场景、参考案例、关键问题。
2. `02-主题内容分析`：与大模型讨论编年/层级/编目/字母表/地理逻辑；判断混合图表、文字列表、词云、照片型、符号型表达；确定标签和叙事命题。
3. `03-数据搜集`：公共数据集、文献、报告、自建数据；登记来源、许可、时间和口径。
4. `04-基础数据集`：一行一个对象/事件/观测；一列一个字段；一个单元格一个原子值。字段可为名义、序数、量化、日期、地理、图像引用或文本。
5. `05-叙事框架`：选择字段组合形成命题，如名称+GPS→地点地图；名称+数值→指标比较。
6. `06-视觉编码`：点线面体、色彩、行距、字距、图像/图形、统计图、ISOTYPE 符号等。
7. `07-信息轮盘测试`：暂留，后续补充测试方法。
8. `08-设计实施`：草图、版式、视觉系统、数据核验、可读性测试、导出归档。

## 数据表原则
每列一个变量；每行明确观察单位；不把多值塞进一个单元格；数值记录单位；分类使用受控词表；图像保存为资源引用；保留原始数据与清洗数据。
