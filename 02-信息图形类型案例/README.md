# 02｜信息图形类型案例：17种市场表现形式

本目录采用两个互不替代的分类维度：

- **五种基础类型学**：唯一主归属，按主导数据/信息关系五选一。
- **17种市场表现标签**：按作品外观、交付形式或使用场景多选，用于检索和制作参考。

ISOTYPE已独立归入仓库根目录的`03-ISOTYPE信息图/`，不是第18个市场标签。Gestalt原则也独立管理。

## 17个标签目录

| 编号 | 标签 | 说明 |
|---|---|---|
| 01 | 混合型 Mixed Charts | 组合统计图表、图符与情境叙事 |
| 02 | 文字型/列表型 Informational / List | 说明、清单、步骤或知识点的组织 |
| 03 | 时间轴型 Timeline | 以时间或阶段序列作为主要表现形式 |
| 04 | 示意图型 How-to | 解释结构、操作、步骤或原理 |
| 05 | 流程图型 Process | 展示流程、节点、分支与反馈 |
| 06 | 比较型 Comparison | 并置对象、指标或方案进行比较 |
| 07 | 地标型 Location | 以地点、地标或空间参照组织信息 |
| 08 | 图片式 Photo-graphic | 摄影图像与信息标注结合 |
| 09 | 层级表现型 Hierarchical | 以视觉层级表现主次或包含关系 |
| 10 | 单一图表型 Single Chart | 以单个统计图表为核心 |
| 11 | 文字可视化 Visualized Text | 以文字形态、排列或编码承载信息 |
| 12 | 解剖型 Anatomical | 展开对象内部结构、组成或部件关系 |
| 13 | 视觉简历 Visual Resume | 个人经历、能力与履历的视觉化 |
| 14 | 手稿型 Hand-drawn | 手绘语言作为主要表现形式 |
| 15 | 编年编目复合型 Chronological + Categorical Hybrid | 同时呈现时间序列与类别组织 |
| 16 | 三维型 3D | 以三维空间或立体结构表现信息 |
| 17 | 词云型 Word Cloud | 以词项及其视觉权重形成词汇概览 |

## 统一归档结构

```text
02-信息图形类型案例/
├── 案例索引.md
├── 案例分析模板.md
├── 案例录入与知识回写规范.md
├── 01-混合型-Mixed-Charts/
│   ├── 00-标签说明.md
│   └── 案例/
│       ├── README.md
│       └── CASE-0001-作品名/
│           ├── 分析.md
│           ├── 基础数据集.csv
│           ├── 数据字典.md
│           └── 原图.png 或 原图来源.md
└── ...其余标签目录
```

每张作品只建立一个CASE目录与一份原图；若作品适合多个标签，其他标签索引以链接指向同一CASE，不复制文件。只有取得再发布权或属于可公开归档的素材才保存原图二进制。
