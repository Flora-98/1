# 01｜信息图形数据逻辑：五种基础类型学

本目录只定义五种基础类型，且它们是全库唯一的基础类型分类。每件信息图形案例必须依据主导的数据/信息关系，选择且仅选择一种主归属；其他组织逻辑作为辅助特征记录。

## 五类索引
- [编年型](./01-编年型信息图形概念定义.md)：顺序、阶段或进程关系。
- [层级型](./02-层级型信息图形概念定义.md)：上下位、包含、从属或等级关系。
- [编目型](./03-编目型信息图形概念定义.md)：类别归属、并列分组与横向比较。
- [字母表型](./04-字母表型信息图形概念定义.md)：按字母、索引键或检索键排列。
- [地理图型](./05-地理图形信息图形概念定义.md)：位置、区域、距离与空间联系。

## 统一研究维度
每份定义统一回答：A基本数据逻辑；B统计图形与计算；C视觉编码；D数据/信息架构；E视觉叙事架构。每个结论应给出可核验证据、边界和反例。

## 分类判断顺序
1. 先识别读者必须理解的主导关系。
2. 检查交换顺序、改变类别、改变父子关系或移除地理位置会破坏什么信息。
3. 选择唯一主归属；可另记辅助逻辑，但不设置第六类。
4. 再到[02案例库](../02-信息图形类型案例/README.md)添加市场表现标签。
5. ISOTYPE与Gestalt分别作为独立方法/原则关联，不参与五类主归属。
