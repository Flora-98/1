# Gestalt 视觉组织原则知识库

本目录将格式塔心理学与视觉知觉组织研究转译为信息图形、信息设计和风格分析方法。

## 分类说明
本库采用三层、12项工作分类，服务学习、检索与实践。**这不是学术界统一认可的固定12项封闭清单，也不意味着各原则处于同一理论层级。**

### 01 基础组织原则
- Prägnanz｜简洁律／良好形式律：总体组织倾向。
- Figure–Ground｜图形与背景关系：图底组织领域。

### 02 经典分组原则
- Proximity｜接近律
- Similarity｜相似律
- Good Continuation｜良好连续律
- Closure｜闭合律
- Symmetry｜对称律
- Common Fate｜共同命运律

### 03 扩展组织原则
- Parallelism｜平行组织原则
- Common Region｜共同区域律
- Connectedness｜连通律
- Synchrony｜同步组织原则

## 易混淆原则
- Prägnanz 是总体组织倾向，不是单一分组规则。
- Figure–Ground 讨论对象与背景的组织。
- Good Continuation 强调平滑路径延续；Connectedness 强调元素直接连接。
- Common Fate 强调共同运动方向或变化轨迹；Synchrony 强调时间上的同时发生。
- Common Region 以共享区域建立归属；Proximity 以空间距离建立归属。

## 使用约定
先确定真实信息关系，再选择视觉组织线索；不得为了套用原则制造关系。风格不变量（间距、线条、分组、层级、对比）与主题变量（数据、对象、地名、文本、叙事）分开记录。设计需接受准确性、可访问性与用户测试检验。
