# Gestalt 原则到风格克隆参数的映射

| 原则 | 可记录参数维度 |
|---|---|
| Prägnanz | 复杂度、规则度、装饰密度 |
| Figure–Ground | 主背景对比、主体分离度 |
| Proximity | 组内／组间间距比 |
| Similarity | 类别编码一致性 |
| Good Continuation | 路径平滑度、方向一致性 |
| Closure | 轮廓完整度、缺口比例 |
| Symmetry | 对称轴、镜像程度 |
| Common Fate | 共同方向、运动节奏 |
| Parallelism | 平行度、线间距 |
| Common Region | 区域边界、背景色差 |
| Connectedness | 连接类型、线宽、端点 |
| Synchrony | 同步窗口、时间标记 |

## JSON 示例
```json
{
  "gestalt_profile": {
    "proximity": {"group_spacing": "tight", "between_group_spacing": "wide"},
    "similarity": {"category_color_consistency": "high"},
    "figure_ground": {"subject_separation": "strong", "background_detail": "low"},
    "continuation": {"path_smoothness": "high"}
  },
  "calibration": {
    "status": "illustrative_not_measured",
    "note": "根据具体参考图校准，不将示例值视为客观测量"
  }
}
```

风格不变量是可重复的视觉习惯；主题变量是数据、对象、地名、文本与叙事。迁移时保持前者稳定，并按新内容重组后者。
