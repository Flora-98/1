# Gestalt案例分析索引

本目录只收录有明确原图或实验材料、可定位来源与可观察证据的案例。教学示意图、研究实验图和真实信息设计作品须分开标注，不得混为同一证据类型。

## 逐例分析字段
- CASE ID、题名、作者/机构、年份、原始来源与版权状态
- 图面内容及信息结构
- 主导Gestalt原则、辅助原则及具体画面证据
- 视觉组织机制与原则协同/冲突
- 信息传达效果、误读风险、可访问性与适用边界
- 可迁移方法与风格参数（风格不变量/主题变量分离）

## 与信息图分类的关系
Gestalt原则不是信息图形类型。每件作品仍须在[五种基础类型](../../01-信息图形数据逻辑/README.md)中选择唯一主归属，并可关联02市场表现标签。一个CASE可被多个Gestalt原则索引引用，但原图与主分析只保存一份。

## 归档规则
- 有权利允许时保存原图；否则保存官方来源与图片URL，并标注“仅外链，未上传原图文件”。
- 每项分析区分可见事实、来源事实与研究者推断。
- 不能仅凭静态截图证明共同命运或同步组织等动态原则。
- 新案例可推动实践方法增补，但未经证据支持不修改已审核的12项原则定义。
