# 03 风格克隆系统

## 目标
从参考图提取可复用视觉风格，而非复制主题内容。分离风格变量与主题变量，使同一风格迁移到不同主题、信息结构和媒介。

## 工作流程
1. 登记参考图、来源、用途、画幅。
2. 解构版式、构图、网格、色彩、字体、线条、形状、图标、图像处理、材质、留白、密度与叙事节奏。
3. 区分不变量、可调变量、主题依赖变量和禁止漂移变量。
4. 参数化：定义参数名、值域、单位、容差和证据。
5. 输出风格签名 JSON，附置信度与未知项。
6. 迁移：替换主题、数据、对象、叙事，不改变风格不变量。
7. 用至少两个不同主题测试风格一致性与适配性。
8. 根据偏差迭代参数。

## 四种交付
中文 JSON、English JSON、中文简易提示词、自然语言提示词。四者必须来自同一份风格签名。

## 质量原则
精准复用须通过参考图分析和跨主题测试验证。单张参考图不能可靠推断未出现的字体、网格或工艺；未知字段标记 unknown 或低置信度。
