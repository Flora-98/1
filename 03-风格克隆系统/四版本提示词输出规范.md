# 四版本提示词输出规范

四个版本由同一份 Style Signature 派生，避免各自发挥造成参数冲突。

## 1 中文 JSON
机器可读，至少包括 style_id、style_invariants、variable_ranges、theme_variables、structure_variables、negative_constraints、unknowns、validation。数值参数带单位或归一化定义。

## 2 English JSON
与中文 JSON 字段语义和参数值一致；翻译说明和值描述，不改变色彩、比例、范围和禁止项。

## 3 中文简易提示词
采用“风格锚点+构图+色彩+字体+图形语言+信息密度+主题替换+禁止漂移”的短格式，保留关键约束。

## 4 自然语言提示词
明确参考风格、必须保持的视觉特征、主题内容、信息逻辑、允许适配项和禁止变化项。避免只用“高级、现代、极简”等不可操作形容词。

## 统一迁移句式
保留 Style Signature 中全部风格不变量；将主题变量替换为[新主题]；根据[数据逻辑/信息结构]重组内容；只在已定义的可调范围内适配版式，不改变色彩关系、字体性格、图形语法、材质与整体视觉密度。

## 失败条件
主题结构与参考风格不兼容时报告冲突并提出最小结构适配，不得静默改变风格。缺少证据的参数保留 unknown。
