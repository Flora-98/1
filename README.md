# 信息图形知识库与风格克隆系统

本仓库以信息图形的数据逻辑、市场表现形式、统计图形分析、ISOTYPE方法、Gestalt视觉组织原则与风格克隆为核心，采用“理论—案例—数据—方法回写”的可验证知识结构。

## 知识体系

- `01-信息图形数据逻辑/`：唯一五种基础类型学。每件作品只能选择一个主归属。
- `02-信息图形类型案例/`：按17种市场表现形式建立检索标签；一图一档，记录原图权利、逐图分析和可复核数据。
- `03-ISOTYPE信息图/`：独立设计方法专项，不属于基础类型或市场表现标签。
- `03-统计图形分析/`：统计图形选择、变量映射、计算口径、尺度与误读控制。
- `03-风格克隆系统/`：风格特征提取、参数化、JSON提示词和跨主题迁移。
- `04-Gestalt视觉组织原则/`：视觉知觉组织原则、案例证据和设计实践。
- `04-XXX主题信息图形设计/`：单主题项目的研究、数据、叙事、编码与实施工作区。

## 分类总规则

### 五种基础类型（唯一主归属，五选一）
1. 编年型：主导关系为有约束的顺序、进程或阶段推进。
2. 层级型：主导关系为上下位、包含、从属或等级。
3. 编目型：主导关系为类别归属、并列分组与横向比较。
4. 字母表型：主导关系为字母、索引键或检索键排序。
5. 地理图型：主导关系为空间位置、区域、距离或地理联系。

不得因外观、标题或装饰形式判类；主归属按读者必须理解的主导信息关系确定。辅助组织逻辑可另行记录，不产生第六种基础类型。

### 17种市场表现形式（多标签检索）
混合型、文字/列表型、时间轴型、示意图型、流程图型、比较型、地标型、图片式、层级表现型、单一图表型、文字可视化、解剖型、视觉简历、手稿型、编年编目复合型、三维型、词云型。它们描述作品形式或应用，不与五种基础类型并列。

### 独立方法与原则
- ISOTYPE：标准化图像符号、重复单位、数量表达与社会信息转译的方法系统。
- Gestalt：知觉组织原则，不是信息图形类型或市场表现标签。

## 案例入库最低标准

每件案例必须先核验来源，再确定唯一基础主归属和可选表现标签；记录A—E五维分析、逐图证据、数据集CSV、数据字典、原图或原图来源说明。原图受版权限制时只保留官方来源链接，明确“外链，未上传原图文件”。不推测作者真实制作流程；重建方法须标注为研究者推演。

## 案例驱动更新

案例归档后，更新案例索引、对应市场标签方法页和必要的01理论文档。01理论文档只放文字与CASE链接，不复制案例图片。任何理论修订均需注明案例证据和适用边界。
