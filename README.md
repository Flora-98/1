# 信息图形知识库与风格克隆系统

本仓库用于建立可持续演进的信息图形知识体系、案例库、视觉组织方法库，以及可跨主题复用的风格克隆提示词系统。

## 知识体系
- `01-信息图形数据逻辑/`：按数据组织逻辑定义信息图形类型。文档不嵌入案例图片，通过链接引用案例库。
- `02-信息图形类型案例/`：保存案例分析与类型方法。案例增加后，回溯更新对应原则与方法。
- `03-风格克隆系统/`：建立风格特征提取、参数化、JSON提示词和跨主题迁移规范。
- `04-XXX主题信息图形设计/`：单个主题项目的研究、数据、叙事、编码与实施工作区。
- Gestalt 原则文档暂缓上传，待用户审核定义后建立。

## 分类约定
1. 编年、层级、编目、字母表、地理图形是数据逻辑/组织方式。
2. 混合型、文字/列表型、时间轴型是信息图形表现类型或案例分类，可能与数据逻辑交叉。
3. ISOTYPE 是基于图像符号、重复单位和数量关系的视觉表达方法/设计系统，不作为与上述类型并列的独立信息图形类别。
4. Gestalt 是视觉知觉与组织原则，不是信息图形类型。
