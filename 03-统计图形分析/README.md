# 03｜统计图形分析

本目录研究统计图形本身的变量表达与计算方法，与信息图形的五种基础组织逻辑分开管理。统计图形是数据表达工具；同一图表可以服务不同基础类型。

## 分析框架
1. 数据与测量：观测单位、变量类型、尺度、统计边界、缺失值与样本范围。
2. 统计任务：比较、分布、构成、关系、变化、空间模式。
3. 图表选择：依据数据结构与分析任务选择图形，不按视觉偏好选图。
4. 视觉映射：位置、长度、角度、面积、体积、颜色、形状、连线等通道。
5. 计算与尺度：聚合、比例、基准、轴范围、分箱、平滑、误差与不确定性。
6. 解释与误读：图例、单位、排序、截断坐标轴、面积/体积误读、颜色可辨性。
7. 可复核性：记录公式、字段、来源、转换步骤和数据字典。

## 与知识库其他部分的关系
- 五种基础类型：决定信息主关系。
- 17种市场表现形式：决定检索标签。
- 统计图形分析：决定如何将变量与统计任务映射为图形。
- ISOTYPE：专门处理标准化图符与重复单位表达。
- Gestalt：解释视觉元素如何被组织与感知。

## 原则
不从图形外观臆测数据；不把无刻度面积当成精确数值；不把相关关系解释为因果；不把等距排版当作等时间间隔。每个案例必须区分图面可转录数据、外部官方补充数据、计算生成数据与无法还原的数据。
